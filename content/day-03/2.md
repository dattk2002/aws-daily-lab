# Biến môi trường và cấu hình local

## Mục tiêu

Tách cấu hình máy local khỏi mã nguồn và giải thích được vai trò của từng biến. Bài kế thừa PostgreSQL đang chạy ở 03-1; chỉ dùng giá trị dummy trong `.env.example`, tuyệt đối không thay bằng mật khẩu cloud để chia sẻ bài tập.

## Hiểu nhanh

`DATABASE_URL` chỉ nơi kết nối PostgreSQL. `HOST` và `PORT` chỉ địa chỉ/cổng tiến trình HTTP lắng nghe; mặc định là `127.0.0.1` và 3000. `PUBLIC_BASE_URL` là địa chỉ client sẽ dùng để mở link ngắn. Ba khái niệm kết nối DB, listen HTTP và URL công khai không hoán đổi cho nhau.

Trong lab local, cả app lẫn PostgreSQL đều chỉ cần truy cập từ máy bạn. `127.0.0.1` luôn nói về máy hoặc network namespace hiện tại. Node chạy trực tiếp trên máy dùng cổng DB được Compose publish trên loopback. Nếu đưa Node vào container khác, `127.0.0.1` sẽ trỏ vào chính container đó; bài này chưa chạy app theo cách ấy.

Node đọc biến từ môi trường tiến trình; tạo một file tên `.env` không bảo đảm mọi chương trình tự nạp nó. Để cách chạy rõ ràng, bài dùng Bash export các giá trị từ file local đã kiểm tra. Không source một file lạ vì cú pháp shell có thể thực thi lệnh. `PGSSLROOTCERT` là tùy chọn cho kết nối TLS có CA ở bài RDS; không đặt đường dẫn giả trong cấu hình local.

## Thực hành

Trong `labs/url-shortener`, tạo file cấu hình từ mẫu nếu chưa có. Nếu `.env` đã tồn tại, mở và đối chiếu thay vì ghi đè:

```bash
cp -n .env.example .env
```

Đọc `.env` trong editor riêng. Cấu hình local mong đợi có dạng dưới đây; `lab` là dummy chỉ cho Compose local:

```dotenv
DATABASE_URL=postgres://lab:lab@127.0.0.1:5432/lab
PORT=3000
HOST=127.0.0.1
PUBLIC_BASE_URL=http://127.0.0.1:3000
```

Nạp vào terminal hiện tại sau khi xác nhận nội dung không có lệnh shell lạ:

```bash
set -a
source .env
set +a
node -e 'console.log({host:process.env.HOST,port:process.env.PORT,base:process.env.PUBLIC_BASE_URL,dbConfigured:Boolean(process.env.DATABASE_URL)})'
```

Lệnh kiểm tra chỉ in trạng thái đã cấu hình DB, không in chuỗi chứa mật khẩu. Một terminal mới không tự thừa hưởng các biến này; cần nạp lại trước khi chạy script demo nếu script không nạp file giúp bạn.

## Kiểm tra kết quả

Kỳ vọng host là loopback, port là 3000, base khớp `http://127.0.0.1:3000` và `dbConfigured: true`. Ghi lại ý nghĩa, không chụp toàn bộ môi trường. Khi tạo link ở 03-4, `shortUrl` phải bắt đầu bằng base này.

Kiểm tra file `.env` được bỏ qua bởi quy tắc Git của repository trước khi ghi cấu hình thật trong các bài sau. Mẫu `.env.example` chỉ được chứa dummy. Một file đã từng được theo dõi không trở nên an toàn chỉ vì thêm quy tắc ignore về sau; nếu đã lộ credentials thật, cần xử lý thu hồi theo hệ thống liên quan.

## Lỗi thường gặp

Copy `.env` nhưng chưa export; port app đổi thành 3001 nhưng base vẫn 3000; nhầm hostname `db` của mạng Compose với địa chỉ khi Node chạy trên host. Đổi `HOST` thành `0.0.0.0` không sửa được một URL public sai và còn có thể mở app cho mạng khác truy cập.

## Dọn dẹp

Giữ `.env` local cho các bài còn lại trong ngày. Khi muốn xóa biến khỏi terminal sau khi dừng app, dùng `unset DATABASE_URL PORT HOST PUBLIC_BASE_URL PGSSLROOTCERT`. Việc unset không xóa file. Không có tài nguyên AWS; DB local tiếp tục dùng volume của bài trước.
