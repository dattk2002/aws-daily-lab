# Cập nhật AL2023 và cài Node.js 22

## Mục tiêu

Chuẩn bị runtime Node.js từ phiên bản 22 trên EC2, kiểm tra đường dẫn executable và ghi lại những thay đổi cần reboot. Chưa copy secrets hoặc chạy ứng dụng trong bài này.

## Hiểu nhanh

Amazon Linux 2023 dùng `dnf`, không dùng `apt` hay công cụ `amazon-linux-extras` của hướng dẫn AL2 cũ. AL2023 có package Node theo major; `node-22` và `npm-22` là tên có version, còn `node`/`npm` đi qua alternatives. Khi cài thêm major khác, tên mặc định có thể thay đổi. Demo dùng Node >=22; chọn 22 nhất quán giúp process manager và shell dùng cùng runtime.

Trước khi cài, EC2 cần DNS và HTTPS outbound để truy cập kho package. Bài lab không yêu cầu NAT gateway nếu đang dùng public subnet có public IPv4 và Internet Gateway hợp lệ. Một SG inbound mở rộng không sửa được lỗi DNS hoặc outbound. Dùng tài khoản quản trị để cài package; ngày 07 sẽ tạo user ứng dụng không sudo.

## Thực hành

Trong phiên EC2 ngày 05-3, đọc bản phát hành hiện tại và xem cập nhật:

```bash
cat /etc/os-release
sudo dnf check-update
sudo dnf upgrade -y
sudo dnf install -y nodejs22 nodejs22-npm git curl
node-22 --version
npm-22 --version
alternatives --display node
```

`dnf check-update` có thể trả exit code 100 khi có bản cập nhật; đó không phải lỗi kết nối. AL2023 khóa kho theo release; `upgrade` cập nhật trong release đã cấu hình. Nếu hướng dẫn bảo mật yêu cầu release mới, đọc release notes, chọn chính xác release hỗ trợ rồi chủ động nâng theo tài liệu AL2023; đừng tự động đổi `releasever` chỉ vì thấy một ví dụ trên mạng.

Nếu `node --version` chưa là major 22, xem các lựa chọn rồi đặt:

```bash
sudo alternatives --set node /usr/bin/node-22
node --version
npm --version
command -v node
```

Ghi phiên bản runtime, ngày cập nhật và việc có cần reboot vào ghi chú. Khi có cập nhật kernel, chọn thời điểm reboot trước khi deploy app; sau reboot mở lại phiên và kiểm tra version lần nữa.

## Kiểm tra kết quả

`node --version` hiển thị `v22...`, `npm --version` trả số hợp lệ, `command -v node` chỉ đường dẫn hệ thống. Chạy `node -e 'console.log(process.platform, process.arch)'` để xác nhận Linux và kiến trúc đã chọn. Không cần mở TCP 3000: cài runtime không tạo HTTP server. Nếu cài đặt thành công nhưng Node chạy khác version, kiểm tra `type -a node` và PATH trước khi cài thêm runtime manager.

## Lỗi thường gặp

`No match for argument nodejs22` có thể do release kho cũ; đọc tài liệu cập nhật AL2023 thay vì chạy script cài đặt từ nguồn không rõ. `sudo npm` để cài dependencies app tạo file root-owned và gây lỗi lần sau. Thiếu RAM khi cài khác lỗi package; đọc kernel log nếu process bị kill.

## Dọn dẹp

Giữ package cho những ngày tiếp theo. Không cần cài PostgreSQL server trên EC2 vì database dùng RDS. Nếu kết thúc, terminate máy lab thay vì chỉ gỡ Node; EBS và IPv4 có vòng đời chi phí riêng. Không xóa log cập nhật trước khi đã ghi lại bằng chứng.
