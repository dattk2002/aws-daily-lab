# Secrets runtime và SSM document có giới hạn

## Mục tiêu

Đưa cấu hình DB vào SecureString, cho EC2 đọc đúng parameter và tạo SSM document chỉ nhận SHA hợp lệ. Runner chỉ upload code và gửi SHA, không có bản sao secret database.

## Hiểu nhanh

Parameter Store SecureString bảo vệ giá trị bằng KMS ở phía dịch vụ; khi đọc có decryption, plaintext tồn tại trên máy cần dùng nó. File `app.env` runtime vẫn cần quyền root:labapp 640 và quy trình rotation. SSM command/logs không phải nơi truyền secret: chúng có thể được người vận hành đọc. Custom document làm hẹp bề mặt gửi command, nhưng người có quyền sửa document hoặc helper vẫn kiểm soát deployment.

## Thực hành

Trong console Parameter Store đúng Region, quản trị tạo `/aws-daily-lab/runtime-env`, type SecureString, key theo chính sách account. Nhập nội dung file môi trường bằng UI an toàn, không paste vào workflow hoặc command arguments. Giá trị chứa các dòng sau với giá trị thật được bảo vệ, không phải placeholder literal:

```bash
DATABASE_URL='postgresql://USER:PASSWORD_DA_URL_ENCODE@ENDPOINT:5432/DATABASE?sslmode=verify-full'
PORT='3000'
HOST='127.0.0.1'
PUBLIC_BASE_URL='https://TEN-MIEN-LAB-CUA-BAN'
PGSSLROOTCERT='/etc/aws-daily-lab/global-bundle.pem'
```

Nếu chưa có domain/HTTPS, dùng base URL thực tế đã được phép của lab; không đặt hostname giả làm kết quả. Giữ format Bash đã dùng ngày 7 vì wrapper source file: chỉ các phép gán đã trích dẫn, không command substitution hoặc shell commands. Chỉ operator đáng tin được sửa parameter. Password có ký tự đặc biệt cần URL encoding; Node demo dùng CA để xác minh TLS. Không thêm AWS_ACCESS_KEY_ID vào parameter. Instance role thêm `ssm:GetParameter` chỉ ARN `arn:aws:ssm:REGION:ACCOUNT_ID:parameter/aws-daily-lab/runtime-env`. Nếu dùng customer-managed KMS key, thêm `kms:Decrypt` chỉ key ARN, key policy cho role và giới hạn service/context phù hợp; AWS managed key có cơ chế riêng cần đọc tài liệu. Không cấp role GitHub quyền đọc parameter.

Từ EC2, quản trị chạy kiểm tra không hiển thị giá trị; file preflight giữ ở /etc thay vì app tree:

```bash
sudo bash -c 'umask 077; aws ssm get-parameter \
  --region ap-southeast-1 --name /aws-daily-lab/runtime-env \
  --with-decryption --query Parameter.Value --output text \
  > /etc/aws-daily-lab/app.env.preflight'
sudo chown root:labapp /etc/aws-daily-lab/app.env.preflight
sudo chmod 640 /etc/aws-daily-lab/app.env.preflight
sudo stat -c '%U %G %a %n' /etc/aws-daily-lab/app.env.preflight
```

Mong đợi root labapp 640. Helper thực hiện cùng quyền khi cập nhật app.env; wrapper đọc file này mỗi lần khởi động. Quản trị dùng editor an toàn kiểm tra format nếu cần; không `cat` vào log. Cài file YAML local sau thành document; agent prerequisite ở bài trước là bắt buộc:

```yaml
schemaVersion: '2.2'
description: Deploy one reviewed URL shortener release
parameters:
  ReleaseSha:
    type: String
    description: Full lowercase Git commit SHA
    allowedPattern: '^[a-f0-9]{40}$'
    interpolationType: ENV_VAR
mainSteps:
  - action: aws:runShellScript
    name: installRelease
    inputs:
      timeoutSeconds: '900'
      runCommand:
        - 'set -eu'
        - '/usr/local/bin/aws-daily-lab-release "$SSM_ReleaseSha"'
```

Lưu `lab-release.yaml` rồi bằng identity quản trị chạy:

```bash
aws ssm create-document --name AwsDailyLab-Release \
  --document-type Command --document-format YAML \
  --content file://lab-release.yaml
aws ssm get-document --name AwsDailyLab-Release --document-version '1' \
  --query Content --output text
```

Nếu tên đã tồn tại, đọc/version review trước, không overwrite mù quáng. Role GitHub chỉ được gửi document này, không được UpdateDocument hoặc dùng `AWS-RunShellScript` tùy ý. Workflow bài sau pin document version `1`.

## Kiểm tra kết quả

Ghi policy đọc parameter có ARN chính xác, KMS key nếu dùng và document version. Thử tham số SHA không đủ 40 hex bằng tính năng validate/document review phải bị từ chối; không cần gửi shell lạ lên máy để chứng minh. Chạy command chỉ sau khi có artifact đúng SHA. Đảm bảo preflight không chứa `.env` ở repository hoặc tar archive và runner chưa từng nhận password.

## Lỗi thường gặp

SSM Agent cũ không xuất ENV_VAR dẫn tới helper thiếu SHA; nâng agent thay vì chuyển sang nội suy chuỗi không kiểm soát. KMS deny khác SSM permission deny; sửa đúng lớp. Secret rotation không tự đổi PM2 process đang chạy, cần release/restart có smoke test. Giữ wrapper source `/etc/aws-daily-lab/app.env` và tránh PM2 lưu bản sao secret trong environment; helper bỏ biến cấu hình khỏi môi trường PM2 trước khi khởi động wrapper.

## Dọn dẹp

Xóa file preflight đúng đường dẫn sau kiểm tra; giữ SecureString và document cho workflow. Có thể có phí parameter nâng cao/API/KMS tùy lựa chọn; không tuyên bố miễn phí. Khi kết thúc toàn lab, xóa đúng parameter `/aws-daily-lab/runtime-env`, document lab và policy attachments sau khi dừng phụ thuộc, không quét xóa parameters toàn account. Không xóa KMS key dùng chung chỉ để dọn bài.
