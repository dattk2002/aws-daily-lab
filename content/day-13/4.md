# Upload bằng AWS SDK JavaScript v3

## Mục tiêu

Chạy một script Node.js độc lập để upload và đọc lại object private. Script dùng danh tính của môi trường thực thi, không sửa API URL shortener và không đưa AWS credentials vào source.

## Hiểu nhanh

SDK chuyển command thành request đã ký. `S3Client` quản lý Region và chuỗi provider credentials; `PutObjectCommand` biểu diễn thao tác ghi. Thành công của một request không làm bucket public. Dùng thư mục thử riêng để dependency SDK không lẫn với package website hoặc package demo. Cần Node.js từ 22, kết nối HTTPS tới endpoint S3 và quyền prefix đã chuẩn bị.

## Thực hành

Trên EC2 có instance role ở bài trước, hoặc máy local đang đăng nhập AWS bằng credentials tạm, tạo thư mục riêng và cài dependency:

```bash
mkdir -p ~/aws-daily-sdk-lab
cd ~/aws-daily-sdk-lab
npm init -y
npm install @aws-sdk/client-s3
```

Lưu nội dung sau thành `upload.mjs`; chỉ truyền tên bucket qua biến môi trường. Đây là file tự viết của người học, không đặt vào website công khai:

```js
import { S3Client, PutObjectCommand, GetObjectCommand } from '@aws-sdk/client-s3';
const bucket = process.env.LAB_BUCKET;
const region = process.env.AWS_REGION;
if (!bucket || !region) throw new Error('Cần LAB_BUCKET và AWS_REGION');
const s3 = new S3Client({ region });
const key = 'scratch/sdk-check.json';
const body = JSON.stringify({ lesson: '13-4', status: 'uploaded' });
try {
  await s3.send(new PutObjectCommand({
    Bucket: bucket, Key: key, Body: body, ContentType: 'application/json'
  }));
  const result = await s3.send(new GetObjectCommand({ Bucket: bucket, Key: key }));
  const loaded = await result.Body.transformToString();
  if (loaded !== body) throw new Error('Nội dung đọc lại không khớp');
  console.log({ key, verified: true });
} catch (error) {
  console.error({ name: error.name, message: error.message });
  process.exitCode = 1;
} finally {
  s3.destroy();
}
```

Đặt lại `LAB_BUCKET` và `AWS_REGION` nếu đây là phiên SSH/SSM mới rồi chạy `node upload.mjs`. SDK không tự biết biến `LAB_BUCKET` trừ khi code đọc nó. Không thêm `credentials: { ... }` để chữa lỗi provider.

## Kiểm tra kết quả

Mong đợi `{ key: 'scratch/sdk-check.json', verified: true }` và exit code 0. Chạy lại để hiểu cùng key bị thay thế khi không dùng versioning. Dùng CLI có quyền quản trị đọc `head-object` để thấy ContentType. Không suy luận thành công từ việc npm cài được: package download và S3 authentication là hai đường mạng khác nhau.

## Lỗi thường gặp

`CredentialsProviderError` là chưa tìm được danh tính; trên EC2 xem profile và metadata options. `AccessDenied` là đã tới bước xét quyền hoặc bị policy chặn; kiểm tra ARN key. `PermanentRedirect` thường do Region sai. Timeout trên private subnet cần đường tới S3 qua endpoint hoặc NAT phù hợp; mở inbound port 443 vào instance không tạo outbound route.

## Dọn dẹp

Giữ script và object cho phép thử âm bài sau. Có phí request/lưu trữ S3 và phí EC2/NAT nếu sử dụng. Khi xong, xóa object đúng key bằng identity quản trị, xóa thư mục local nếu không còn cần. Không thêm DeleteObject vào runtime role chỉ để tiện dọn; có thể giữ nhiệm vụ dọn cho người vận hành.
