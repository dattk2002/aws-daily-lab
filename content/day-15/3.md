# Test hợp đồng API bằng native Node

## Mục tiêu

Viết một test chạy server thật, tạo link qua HTTP và xác minh redirect cùng dữ liệu PostgreSQL. Test phải đỏ nếu API trả sai mã trạng thái hoặc URL đích, không chỉ kiểm tra process sống.

## Hiểu nhanh

Native `node:test` và `node:assert/strict` có sẵn trên Node 22. Bài dùng blackbox test để không phụ thuộc tên hàm nội bộ của demo. Cần `npm ci`, PostgreSQL tạm và `npm run db:init` ở bài trước. Test tạo dữ liệu thử và xóa đúng code sau khi chạy, không TRUNCATE một DB dùng chung. Chỉ chạy trên DB local/CI dành riêng.

## Thực hành

Trong `labs/url-shortener`, lưu bài tập thành `test/ci-contract.test.mjs`. Snippet khởi động bằng `npm start`, nên không đoán file entrypoint. Nó dành cho runner Linux của giáo trình:

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { spawn } from 'node:child_process';
import pg from 'pg';

test('tạo link lưu DB rồi redirect đúng URL', { timeout: 20000 }, async t => {
  assert.ok(process.env.DATABASE_URL, 'Cần DB thử riêng');
  const base = 'http://127.0.0.1:3100';
  const child = spawn('npm', ['start'], {
    detached: true, stdio: 'inherit',
    env: { ...process.env, HOST: '127.0.0.1', PORT: '3100', PUBLIC_BASE_URL: base }
  });
  const pool = new pg.Pool({ connectionString: process.env.DATABASE_URL });
  let code;
  t.after(async () => {
    try {
      if (code) await pool.query('DELETE FROM links WHERE code = $1', [code]);
    } finally {
      await pool.end();
      try { process.kill(-child.pid, 'SIGTERM'); } catch (e) {
        if (e.code !== 'ESRCH') throw e;
      }
    }
  });
  let ready = false;
  for (let i = 0; i < 50; i++) {
    if (child.exitCode !== null) throw new Error('Server thoát trước readiness');
    try {
      const res = await fetch(`${base}/ready`, { signal: AbortSignal.timeout(500) });
      if (res.status === 200) { ready = true; break; }
    } catch {}
    await new Promise(r => setTimeout(r, 100));
  }
  assert.ok(ready, 'Server phải ready trong khoảng chờ');
  const alive = await fetch(`${base}/health`);
  assert.deepEqual(await alive.json(), { status: 'ok' });
  const target = 'https://example.com/ci-contract';
  const created = await fetch(`${base}/shorten`, {
    method: 'POST', headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ url: target })
  });
  assert.equal(created.status, 201);
  const body = await created.json();
  code = body.code;
  assert.equal(typeof code, 'string');
  assert.ok(code.length > 0);
  assert.equal(body.shortUrl, `${base}/r/${code}`);
  const stored = await pool.query('SELECT url FROM links WHERE code = $1', [code]);
  assert.equal(stored.rows[0]?.url, target);
  const redirected = await fetch(`${base}/r/${code}`, { redirect: 'manual' });
  assert.equal(redirected.status, 302);
  assert.equal(redirected.headers.get('location'), target);
});
```

Chạy `node --test test/ci-contract.test.mjs` sau init. Thêm lệnh đó sau `npm test` vào job PostgreSQL. Nếu `npm test` đã tự tìm file mới, tránh chạy trùng và bảo đảm không có hai test server tranh port 3100; có thể đặt bài tập ngoài pattern test mặc định và chỉ gọi explicit.

## Kiểm tra kết quả

Mong đợi một test pass, database có bản ghi trong lúc kiểm tra và bản ghi được xóa sau test. Tạm đổi expected redirect thành 301 trong bài tập để thấy fail, rồi khôi phục 302 và chạy lại. Thao tác này chỉ sửa assertion local, không sửa production để làm thử. Không gọi Internet: `redirect: manual` giữ kiểm tra ở API của bạn.

## Lỗi thường gặp

Port đã dùng có thể khiến test nói chuyện với process cũ; dọn process của đúng bài, không kill hàng loạt Node. `detached` và kill process group ở đây dành cho Linux/macOS, không phải PowerShell Windows native. `catch {}` chỉ bao quanh readiness retry, không được bọc toàn test rồi bỏ lỗi. Không dùng DATABASE_URL production để tiện bỏ service.

## Dọn dẹp

Hook xóa đúng code và kết thúc process group. Nếu runner bị hủy đột ngột, database tạm bị hủy cùng job. Local cần xác nhận process thử dừng và DB test có thể bỏ. Không lưu response có dữ liệu người dùng thật trong artifact; input bài tập cố định không nhạy cảm.
