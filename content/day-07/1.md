# Đặt mã nguồn dưới quyền user ứng dụng

## Mục tiêu

Đưa repository của chính bạn vào `/opt/aws-daily-lab`, dùng user Linux `labapp` không có sudo và xác nhận đường dẫn demo `labs/url-shortener/`. Không clone dự án tham khảo bên ngoài rồi giả định các endpoint giống nhau.

## Hiểu nhanh

Phiên `ec2-user` có quyền quản trị để cài hệ thống, nhưng process Node chỉ cần đọc code, đọc cấu hình runtime và kết nối database. Cho app chạy root làm tác động của một lỗi lớn hơn cần thiết. Quyền sở hữu phải giới hạn vào thư mục của app, không `chown -R /opt`, `/etc` hoặc home của người khác.

Điều kiện trước bài: EC2 AL2023 có Git/Node 22, kết nối được RDS bằng TLS, role DB `labapp` và bảng `links` đã có. Repository cần là bản AWS Daily Lab chứa demo nguyên gốc, có `package-lock.json`; root package là giao diện web, không phải HTTP API. Với repository private, dùng cơ chế truy cập Git được cho phép hoặc chuyển một source archive đã kiểm tra; không nhét personal token vào URL clone.

## Thực hành

Trong phiên quản trị, tạo user và chỉ cấp đường dẫn đích:

```bash
sudo useradd --create-home --shell /bin/bash labapp
sudo install -d -o labapp -g labapp -m 755 /opt/aws-daily-lab
sudo -iu labapp
```

Nếu user hoặc thư mục đã có, kiểm tra `id labapp` và `ls -ld /opt/aws-daily-lab`; không tạo lại hay ghi đè code đang dùng. Trong shell `labapp`, clone nguồn bạn sở hữu vào thư mục trống đã tạo:

```bash
git clone '<URL_HTTPS_REPOSITORY_AWS_DAILY_LAB_CUA_BAN>' /opt/aws-daily-lab
cd /opt/aws-daily-lab
git rev-parse HEAD
test -f labs/url-shortener/package.json
test -f labs/url-shortener/package-lock.json
cd labs/url-shortener
pwd
node --version
```

Thay URL trước khi chạy. Nếu có release/SHA được duyệt, checkout đúng SHA đó trước khi cài dependencies và ghi SHA vào sổ triển khai. Không chạy `npm install` ở root vì nó cài UI; không dùng source upstream của khóa tham khảo thay cho demo trong repo này. Kiểm tra `id` để chắc user app không thuộc nhóm sudo/wheel; quyền admin vẫn ở phiên `ec2-user` riêng.

## Kiểm tra kết quả

`pwd` phải là `/opt/aws-daily-lab/labs/url-shortener`, Node là 22 trở lên, SHA được ghi nhận. `ls -ld /opt/aws-daily-lab /opt/aws-daily-lab/labs/url-shortener` cho thấy user app sở hữu đường code được cấp. Không có password RDS hoặc access key trong URL remote, command history hay source. Dùng hai phiên rõ ràng: quản trị cho package/service, app user cho dependencies/process.

## Lỗi thường gặp

Permission denied tại `/opt` được sửa bằng tạo chính xác thư mục đích, không mở quyền 777. Clone vào thư mục đã có nội dung sẽ thất bại có chủ đích; xác định nội dung hiện có trước. Chạy nhầm root package có thể build giao diện thành công nhưng vẫn không có server ở 3000.

## Dọn dẹp

Giữ source và user cho các bài tiếp theo. Xóa archive tạm chứa code chỉ sau khi kiểm tra không có secret và không cần phục hồi. Không xóa user trong khi còn process dùng nó. EC2/RDS vẫn chạy và có thể tính phí; nếu ngừng lab, teardown tài nguyên theo ID đã ghi, không xóa cả thư mục `/opt` của máy.
