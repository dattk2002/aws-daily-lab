# Capstone: checklist triển khai có điểm dừng

## Mục tiêu

Triển khai theo các checkpoint có kết quả quan sát được. Phần local có thể chạy độc lập; phần AWS chỉ thực hiện nếu bạn chủ động chọn scope cloud ở20-1 và đã chuẩn bị các lab ngày4–10/17, không phải script tự tạo hạ tầng.

## Hiểu nhanh

Một checklist tốt cho phép dừng ở lớp lỗi thay vì đẩy tiếp cấu hình hỏng ra ngoài. App nằm ở `labs/url-shortener`; package root dành cho giao diện học, không khởi tạo DB demo. Các lệnh npm dưới phải chạy trong đúng thư mục app. Credentials mẫu `lab` chỉ dành cho PostgreSQL container local, không dùng trên RDS.

## Thực hành

### Checkpoint local

Cần Node.js >=22.9, npm, Docker Engine/Desktop và Docker Compose v2; terminal Bash tại repository. Kiểm tra `node --version`, `docker compose version` và Docker daemon hoạt động. Tại app chạy:

```bash
cd labs/url-shortener
npm ci
cp .env.example .env
docker compose -f compose.yaml up -d --wait
npm run db:init
npm test
npm start
```

Chỉ `cp` khi chưa có `.env` của bạn; nếu đã có, mở file và so các key thay vì ghi đè. `.env` local phải dùng DB trên localhost, `HOST=127.0.0.1`, `PORT=3000`, `PUBLIC_BASE_URL=http://127.0.0.1:3000`; không chép cấu hình production vào máy demo. `up --wait` đợi trạng thái Compose/healthcheck; kiểm tra `docker compose ps` và log PostgreSQL nếu schema init vẫn lỗi. `npm start` giữ terminal mở, dùng terminal thứ hai cho curl.

Mong đợi `/health` trả JSON `{"status":"ok"}`, `/ready`200. Nếu `db:init` thất bại, dừng và xử lý DB trước; không bỏ qua rồi chỉ chụp giao diện. Kiểm thử unit không thay kiểm tra tích hợp với container thực.

### Checkpoint cloud nếu đã chọn

1. Ghi account, Region, VPC/subnet/SG IDs, RDS identifier, ALB/target group ARN, EC2 hoặc ASG ID cùng release SHA. Có IAM tạm, quyền tối thiểu và ngân sách quan sát; không dùng root cho deploy. Cloud bước này có phí EC2/EBS/IPv4, ALB, RDS/backup/logs; không hứa Free Tier.
2. Xác minh RDS available, private, SG5432 nguồn SG app, CA đúng. Trên app EC2 có PostgreSQL client và quyền DB tạo schema phù hợp, xác minh kết nối TLS như19-2. Chạy `npm run db:init` một lần trong thư mục app bằng user `labapp` và runtime configuration đã chuẩn bị ngày6–7; không nhập DB secret vào lệnh/log và không chạy schema init ở mọi boot ASG.
3. Deploy artifact/SHA đã test qua quy trình ngày7/16, ownership chỉ user `labapp` trong `/opt/aws-daily-lab/labs/url-shortener`, cài production dependencies bằng `npm ci --omit=dev`. PM2 process tên `aws-daily-lab`. Nếu chọn ASG, cần AMI sạch, launch template version và bootstrap đã nghiệm thu17-2, không lấy ảnh còn password.
4. Check tại máy: Node loopback3000 `/health` và `/ready`200; `sudo nginx -t` thành công; Nginx80 `/health`200. Xem PM2 status bằng đúng user `labapp`. App không mở port3000 ra Internet. Reboot một máy lab rồi kiểm tra lại quản lý process để chứng minh khả năng khởi động lại.
5. Target group healthy path `/health`, port80, SG ALB/app đúng; listener trỏ target group. Từ client IP được phép, kiểm tra ALB `/ready` rồi create/redirect theo20-3. HTTPS chỉ nghiệm thu với domain bạn sở hữu, DNS validation và certificate cùng Region ALB đã hoàn tất; nếu chưa có thì ghi HTTPS chưa làm.

## Kiểm tra kết quả

Mỗi checkpoint cần một dòng timestamp, lệnh/quan sát và pass/fail. Dừng khi local DB chưa ready, cloud TLS fail, proxy502 hoặc target unhealthy. Chỉ đánh dấu tuyến cloud hoàn tất khi request nghiệp vụ đi từ client qua ALB tới DB và redirect đúng; test local hoặc PM2 online không đủ.

## Lỗi thường gặp

Chạy npm ở root có thể build website học thay vì app. `.env` local trỏ container host không phù hợp với EC2. Nginx config sai nhưng chưa reload có thể khiến file đúng khác cấu hình đang chạy. Trong ASG, đổi code một EC2 bằng tay không cập nhật template; máy thay thế sẽ quay về release cũ.

## Dọn dẹp

Giữ app/container local cho20-3; Ctrl+C dừng Node nếu cần nghỉ. Giữ volume để không mất link thử; `docker compose -f compose.yaml down` dừng stack nhưng không xóa volume mặc định. Cloud chỉ giữ tới20-5 trong cùng buổi nếu có thể; ghi rõ những tài nguyên giữ qua ngày và thời điểm dọn, không để quy trình kiểm thử đồng nghĩa chạy vô thời hạn.
